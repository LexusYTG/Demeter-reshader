## Окружение сборки

Demeter был написан и скомпилирован с:

- JDK 7 (Oracle или OpenJDK 7)
- Android SDK 29
- Gradle 1.x
- Android Gradle Plugin 1.x

Любой может воспроизвести это окружение, установив именно эти версии. AIDE не обязателен — AIDE автор использует в повседневной работе для удобства на телефоне, но проект собирается и стандартным тулчейном 2014 года.

---

## Вариант A — AIDE (рекомендуется на телефоне)

1. Установи AIDE из Play Store (версия 3.x или выше).
2. Открой репозиторий как существующий проект.
3. Build → Run. Готово.

---

## Вариант B — Десктоп (JDK 7 + SDK 29 + Gradle 1.x)

1. Установи JDK 7 (Oracle или OpenJDK).
2. Скачай Android SDK 29 из архивов Google.
3. Установи Gradle 1.x — не 4 и не 7.
4. Настрой `ANDROID_HOME` на путь к SDK.
5. Запусти `gradle assembleDebug`.

Если получится портировать на современный Gradle и хочешь внести порт — присылай PR. Вклады приветствуются.

---

## Почему Java 7?

Потому что реальная цель Demeter — бюджетные телефоны с Android 13 и 4 ГБ RAM (Unisoc T606, Helio G85, Mali-G57 MP1), а не Pixels. Лямбды, стримы и try-with-resources из Java 8 дают overhead по аллокациям, который на этих чипах ощущается. Java 7 — не каприз, а правильное техническое решение для этой цели.

## Что НЕ нужно

- Современный Android Studio
- Gradle 7+
- Java 8+
- Kotlin
- Kotlin DSL
- Внешние зависимости

В проекте нет ни одной сторонней зависимости. Всё, что используется, идёт из стандартного Android SDK.
